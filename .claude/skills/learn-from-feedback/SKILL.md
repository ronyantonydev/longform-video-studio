---
name: learn-from-feedback
description: Turn feedback on a video into fixes for that video and approved lessons for its channel.
---
Read channels/<c>/videos/<v>/feedback.txt (or the user's message). Fix what is specific to this video.
Sort each comment into: pacing, shot-match, voice, facts, music, captions, hook, structure, images.
Propose general rules in plain words and ask the user to approve each one before adding it to
.engine/channels/<c>/learned-style.md. Lessons belong to that channel only. Never add a rule without
approval. Track rejected shots and review time per video so improvement can be measured.
